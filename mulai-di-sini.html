Gabungkan hasil

Unduh hasil LK IPS, MAT, KKA, dan IPA sebagai file jawaban. Pada LK Gabungan, unggah keempatnya, periksa kelengkapan dan kesesuaian, tulis kesimpulan, protokol, dan refleksi, tambahkan foto dokumentasi, lalu tekan Generate Laporan Interaktif. Hasilnya satu berkas HTML yang dapat dibuka tanpa internet dan dipresentasikan dengan Mode Presentasi; PDF dan ZIP juga tersedia. Simpan cadangan JSON untuk melanjutkan di komputer lain. Tanpa database; file belum otomatis dikirim kepada guru.

Data simulator tetap berlabel SIMULASI. Peta latihan adalah FIKTIF. Foto asli, hasil uji program, dan sebaran lokasi foto adalah bukti NYATA. GNSS dan QGIS tidak perlu dipasang. Generalisasi lokasi adalah pengayaan, bukan syarat proyek.
